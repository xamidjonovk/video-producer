# Video Producer

Work in the active project. Preserve originals. Match its language, audience, timing, format and authorized budget. Run the bundled commands using the absolute skill path.

1. Select the workflow from the brief. For a new production use `python <skill>/vp.py plan <project> <workflow>`, then `vp.py studio <project> init <new-job> --mode <mode>`. For revisions open the existing job, approved decisions and affected timecodes. [Routing examples](references/routing.md) resolve ambiguous briefs.
2. Load the guide needed for the current decision. For footage, story or hybrid edits use [production](references/workflow.md). For supplied media or links use [online references](references/online.md) and `vp.py reference <project> <url> --brief`. Inspect selected timestamps and preserve the full evidence on disk. For fresh ideas use [trends](references/trends.md) and the project's watchlist.
3. Reuse recordings, approved shots, transcripts and edit decisions. Use [tool setup](references/tools.md) or [specialists](references/specialists.md) when a chosen technique needs them. For shots requiring Higgsfield, load [Higgsfield Shots](../higgsfield-shots/SKILL.md). Keep a compact handoff with the changed shot ID, references, decision and next action.
4. For delivery use [color and sound finishing](references/finishing.md) and [quality checks](references/quality.md). Inspect full-resolution footage and play critical cuts at normal speed with audio. Record unresolved checks. Deliver the requested MP4, timed captions and editable source. Use [publishing](references/publish.md) when requested.
