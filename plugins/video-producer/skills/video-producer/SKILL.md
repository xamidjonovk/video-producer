# Video Producer

Use the absolute path to this skill directory for commands. Work in the active video project and preserve source media. Read the project's instructions and follow [reference intake and production](references/workflow.md).

1. Interpret the ordinary prompt yourself. Identify the desired deliverable, audience, aspect ratio, duration, language, required footage and budget. Infer what you can from links, source files and the prior task. For editing work, preserve the existing assets and use a fresh job folder. [Routing examples](references/routing.md) map user intent to workflows.
2. Run `python <skill>/vp.py plan <project> <workflow>` for the selected workflow. Reuse available capabilities. Run local operations directly. The `studio`, `transcribe`, `engine`, `reference`, `scenes` and `sfx` commands prepare required dependencies as needed. Use `prepare openscreen` if the task calls for that recorder and it is absent. Try the verified upstream or connected alternative if a required engine fails. Use [Tool selection](references/tools.md) and [specialist tools](references/specialists.md) when needed. Surface a missing permission, account or material decision if it blocks the job.
3. Sync local files into the reference index. For Instagram or YouTube, follow [online references](references/online.md) to inspect a bounded profile sample or a single clip. Track what was observed, then carry useful patterns into original footage, narration, framing and edits. Use the project's `watchlist.local.json` if supplied and [the trend workflow](references/trends.md) when the task needs fresh ideas.
4. Use `vp.py studio <project> init <job> --mode <mode>` for a production folder. For edits, preserve natural speech and inspect duration, orientation, HDR and audio. Generate the rough cut, plan B-roll, synchronize subtitles and mix in the chosen editor. For new content, write story beats and shot timing before selecting visual and audio tools. Match the user's language and use native audio where possible. Read [quality checks](references/quality.md).
5. For paid generated shots, read [credit budgeting](references/higgsfield.md). Estimate the exact model, inputs, duration, resolution and variants. Run `credit_plan.py` against the authorized amount. Reuse usable render IDs and references, use draft mode only when it reduces expected retake cost, and test the hardest shot before committing the batch. Keep within the authorized spend.
6. Apply [color and sound finishing](references/finishing.md) and inspect the final output. Check picture, timing, loudness and true peak. Fix technical review flags before delivery. Play the important cuts at normal speed with sound when playback is available and record what still needs editorial review. Deliver MP4, timed SRT and editable source or edit plan as requested. Prepare caption, cover and draft when requested. Use the [publishing workflow](references/publish.md) for approved destinations and schedules.
