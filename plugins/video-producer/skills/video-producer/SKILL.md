# Video Producer

Use the absolute path to this skill directory for commands. Work in the active video project and preserve source media. Read the project's instructions and follow [reference intake and production](references/workflow.md).

1. Interpret the ordinary prompt yourself. Identify the desired deliverable, audience, aspect ratio, duration, language, required footage and budget. Infer what you can from links, source files and the prior task. For editing work, preserve the existing assets and use a fresh job folder. [Routing examples](references/routing.md) map user intent to workflows.
2. Run `python <skill>/vp.py plan <project> <workflow>` using the workflow you selected. Treat its tool list as candidates to choose between. Run `doctor` when local inspection or rendering is useful. Check which native tools or official connectors the current host actually exposes. Apply the needed local dependency with `vp.py prepare <project> <engine>` or the verified upstream recipe and keep working in the same request. For independent tasks, use the relevant stages from [Tool selection](references/tools.md). [Specialist tools](references/specialists.md) covers tools used only for specific cases. Request a user action only when the brief has a material unresolved decision, a permission or account prompt blocks a capability, or permission is required for paid generation or publishing.
3. Sync files into the project reference index with `python <skill>/references_tool.py sync <project>`. Register supplied Instagram or YouTube links with `add`. Use local footage, prior reference notes, and reliable metadata first. Fetch only the portions needed to study pacing and visuals. Preserve provenance and timecode evidence. Use the project's `watchlist.local.json` if supplied and [the trend workflow](references/trends.md) when the task needs fresh ideas.
4. Use `vp.py studio <project> init <job> --mode <mode>` for a production folder. For edits, preserve natural speech and inspect duration, orientation, HDR and audio. Generate the rough cut, plan B-roll, synchronize subtitles and mix in the chosen editor. For new content, write story beats and shot timing before selecting visual and audio tools. Match the user's language and use native audio where possible. Read [quality checks](references/quality.md).
5. For paid generated shots, read [credit budgeting](references/higgsfield.md). Estimate the exact model, inputs, duration, resolution and variants. Run `credit_plan.py` against the authorized amount. Reuse usable render IDs and references, use draft mode only when it reduces expected retake cost, and test the hardest shot before committing the batch. Keep within the authorized spend.
6. Deliver the requested media, subtitles and editable source, or edit plan. Check final dimensions, duration and audio, then play the important cuts at normal speed with sound when playback is available. Record unverified lip sync or motion when only stills or transcript are accessible. Prepare caption and cover when requested. Publish only to the explicitly approved destination and with the approved media and text.
