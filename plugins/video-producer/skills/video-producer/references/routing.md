# Route ordinary requests

Understand the intent semantically. Use these examples for orientation. File type, constraints and requested output can change the route.

| User may say | Workflow | Start here |
| --- | --- | --- |
| “Shu xom videoni 40 soniyalik Reelga aylantir, pauzalarni olib tashla” | `raw-edit` | Inspect the video and any existing captions, cut at thought boundaries, and export a vertical version. Add TTS or motion only if requested or needed to make the edit clear. |
| “Make three clips from this interview” | `repurpose` | Transcribe or reuse captions, choose complete sound bites, check portrait framing and create individual jobs. |
| “O‘zbekcha subtitr qo‘sh” | `subtitles` | Reuse timed text first, then use local multilingual speech recognition or an authorized provider. Check names and translate only if requested. |
| “Show how to use this app in 30 seconds” | `screen-demo` | Record a short real interaction or use the supplied demo clip. Clarify the workflow with captions or a minimal overlay. |
| “Give this an animated title and captions” | `html-motion` | Reuse the native editor or select HTML motion when timed layers need a reusable coded effect. |
| “Make a video from our dashboard data” | `react-motion` | Check the existing code and select a React/data or HTML renderer based on the actual assets and deliverable. |
| “Produce a launch film for our product” | `launch-film` | Build a beat sheet and decide whether actual UI, kinetic graphics, custom scoring or generated shots contribute. |
| “Explain this topic in under a minute” | `explainer` | Verify needed facts, write for speech, then choose the smallest compatible render and voice pipeline. |
| “Camera moves through the whole piece in one take” | `one-shot` | Plan a continuous camera path and test seams. |
| “Replace the background but keep hair natural” | `composite` | Preserve the take, test a matte and inspect edges in motion before all frames are processed. |
| “Noldan zamonaviy cinematic rolik qil” | `cinematic` | Make original story beats, character reference plates, and a budgeted representative motion test as authorized. |
| "Eski iPhone videomdagi yuzimni saqlab, yangi matnni o‘z ovozimda gapirtir" | `presenter-clone` | Lock the voice, select real footage, prepare a short pair, and route it to Sync Lipsync 3. |
| “Find formats getting traction this week” | `trend-research` | Use current, comparable evidence and turn findings into original hooks. |
| “Prepare it for Instagram or YouTube” | `publishing-draft` | Verify aspect ratio and caption, then prepare the MP4 and publication package. |

The plan command is read-only. Once the appropriate tools are selected, use them to produce or revise the requested result. Use the existing source material, edit timeline and captions when continuing an existing job. Use the user's language for instructions, scripts, captions and feedback unless they request another language.
