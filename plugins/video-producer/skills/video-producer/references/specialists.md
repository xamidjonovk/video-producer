# Specialist tools and upstream skills

Use these only when the task needs them and the environment can run them. Use the upstream license and setup instructions for the version in use. Load one useful specialist workflow, then return its output to the active project.

| Capability | When and how to use it |
| --- | --- |
| Instagram viral research, reference analysis and caption QA | Use the built-in trend workflow first. When the job needs deeper hook, reference or caption analysis, consult `ig-viral`, `ig-reel` or `ig-caption` from [instagram-agent-skill](https://github.com/Jakeschincariol/instagram-agent-skill). |
| YouTube outliers and hooks | Prefer authorized vidIQ data or comparable public channel data. Consult the paired `yt-viral` and `yt-script` skills only when their hook formulas or research checks fit. [youtube-agent-skill](https://github.com/Jakeschincariol/youtube-agent-skill) |
| Talking-head editing | Use the built-in pause detector and transcript review first. For filler cleanup, punch-ins, audio cleanup or chapters, use the selected techniques from [video-editing-skill](https://github.com/social-media-skills/video-editing-skill). Use [Ghost Editor](https://github.com/kurbaitaev/ghost-editor) for a compatible macOS talking-head pipeline when it offers a specific benefit. |
| Resolve-specific editing | Use the [official Resolve editor and scripting tools](https://www.blackmagicdesign.com/products/davinciresolve). Follow the documented MCP integration when the installed edition exposes it. Use [video-editor-skills](https://github.com/appariciojunior/video-editor-skills) only in contexts allowed by its terms. If an NLE import cannot be verified, deliver the edit plan and timed SRT. |
| HyperFrames and Remotion specialist skills | Match the installed engine version and load its official skill for the needed operation. Use the minimal rendering, captions, animation, audio or asset-management guidance that solves the problem. [HyperFrames](https://github.com/heygen-com/hyperframes), [Remotion](https://www.remotion.dev/docs/ai/skills) |
| Full alternative production pipeline | Use [OpenMontage](https://github.com/OpenMontageInc/OpenMontage) as an alternative for a job that specifically benefits from its provider stack or pipeline. Run it in its own workspace and exchange source files, timeline or rendered clips. Read role-specific guidance from [video-agent-skills](https://github.com/Melvynx/video-agent-skills) or [video-use](https://github.com/browser-use/video-use) only for a workflow the base edit path cannot cover. |
| Local transcription and shot boundaries | Prefer supplied subtitles. Use `vp.py prepare <project> transcription` and `vp.py transcribe <project> <source> <out.srt> --language uz` for local Whisper captions. For multi-shot footage use [PySceneDetect](https://github.com/Breakthrough/PySceneDetect) and its `detect-content list-scenes` workflow when shot timestamps are needed. [faster-whisper](https://github.com/SYSTRAN/faster-whisper) |
| Retrieve reference media | Use a user-supplied file or upstream export first. Run [yt-dlp](https://github.com/yt-dlp/yt-dlp) only for an authorized download, with no account cookies or access-barrier bypass. Research from metadata, own transcripts or a connector when download is unnecessary. |
| Sound selection, Foley and audio QA | Use tracks and approved recordings already in the project. [Earshot](https://github.com/Leonxlnx/earshot) can help rank effects, inspect timing or synthesize selected Foley when needed. Read its pinned install and skill instructions before running it and verify mix quality with playback. |
| Matting and background replacement | Prefer the current NLE's Magic Mask workflow where available. Use [SAM 2](https://github.com/facebookresearch/sam2) for object masks and tracking. Use [MatAnyone](https://github.com/pq-yang/MatAnyone) for soft alpha around edges when the available GPU and model terms fit. Verify moving edges before using in the final composite. |
| Local AI video | Reuse a working [ComfyUI](https://github.com/Comfy-Org/ComfyUI) workflow with compatible weights and license. Consider [Wan 2.2](https://github.com/Wan-Video/Wan2.2) or [LTX 2.x](https://github.com/Lightricks/LTX-2) for local generation when the brief, time and VRAM fit. Check the exact checkpoint and validate one short shot in the intended aspect ratio before downloading more models. |
| Hosted image, video and audio | Use host-provided authorized ImageGen for reference stills, Higgsfield for quoted video generation, and ElevenLabs for voice, Scribe or available video capabilities. Prefer the provider that satisfies the exact shot and authorized budget. Never assume the user's existing subscription covers a model or connector charge. |

Keep hook and trend research, structured scriptwriting, visual direction and prompting, footage analysis and edit planning, and audiovisual QA as stages of the main skill. For each hook include the first line and opening image. Put shot direction, durations, material sources and spoken language in the script. Check output picture and audio with timestamped notes.
