# Video Producer

When asked to install this repository, read the installation section in [README.md](README.md). Install the official marketplace plugin for the current host or use the shared local skill installer when that catalog is unavailable. Run the diagnostics and tell the user which features are ready.

When asked to make or edit a video, read [the Video Producer skill](plugins/video-producer/skills/video-producer/SKILL.md) and work in the user's video project. Treat this checkout as shared tooling. Keep media, credentials and personal watchlists out of it.
